# 사진 빠른 분류

Android 휴대전화에서 여러 사진을 고른 뒤 사진마다 앨범 이름 버튼을 하나 이상 선택하고 **다음**을 눌러 각 로컬 갤러리 앨범으로 복사하는 오프라인 앱입니다. 원본 사진은 수정하거나 삭제하지 않습니다.

## 실행과 권한 확인

처음 실행하면 앱이 사진 접근 용도를 설명합니다. 사용자가 **확인하고 권한 요청**을 누른 다음 Android의 시스템 권한 창에서 허용 여부를 정합니다. **나중에**를 누르면 권한 없이 기본 화면을 볼 수 있으며, **앨범 추가**나 **휴대전화 갤러리에서 사진 고르기**에서 다시 요청할 수 있습니다. Android 14 이상에서 일부 사진만 허용하면 앱에 보이는 앨범과 사진 수가 제한될 수 있습니다. 앱으로 돌아오면 권한과 앨범 목록을 다시 확인합니다. 권한을 계속 거부한 경우에는 다시 요청하거나 Android 앱 설정으로 이동할 수 있습니다.

분류할 사진은 앱 안의 휴대전화 갤러리 화면에서 선택합니다. 이 화면은 기기의 MediaStore에 등록된 로컬 사진과 앨범을 읽으므로 사진 접근 권한이 필요합니다. 삼성 갤러리 앱 자체를 앱 안에서 실행하는 방식은 아닙니다. Android 14 이상에서 일부 사진만 허용하면 허용된 사진만 이 화면에 보입니다. Android 8~9에서는 공유 사진 폴더에 저장하기 위한 쓰기 권한도 함께 요청합니다. 접근성 권한, 모든 파일 접근 권한, 인터넷 권한은 사용하지 않습니다.

## 사용 방법

1. **앨범 추가**를 눌러 표지와 사진 수가 표시된 로컬 앨범을 선택합니다. 선택하면 등록 화면으로 돌아옵니다. 원하는 앨범이 보이지 않으면 앱에서 **새 앨범**을 등록할 수 있습니다. 새 앨범은 첫 사진을 복사할 때 실제로 만들어집니다.
2. 홈에서 등록된 앨범 이름을 확인합니다. 사진 분류 화면에는 등록된 앨범 이름이 그대로 선택 버튼에 표시됩니다.
3. **휴대전화 갤러리에서 사진 고르기**를 누릅니다. 앱의 사진 선택 화면에서 원하는 로컬 앨범을 열고 사진을 여러 장 고른 뒤 **선택한 사진 분류하기**를 누릅니다. 기본 목록에서는 앱이 분류 기록으로 인식한 사진과 앱이 만든 복사본이 숨겨집니다. 다시 고르려면 **분류한 사진 보기**를 켭니다. 과거에 만든 파일 등 인식할 수 없는 복사본은 목록에 남을 수 있습니다.
4. 현재 사진을 넣을 앨범 버튼을 하나 또는 여러 개 누릅니다. 선택한 버튼은 색이 진해지며, 같은 버튼을 다시 누르면 선택이 해제됩니다. 버튼을 고르는 동안에는 복사하지 않습니다.
5. **다음**을 누르면 선택한 각 앨범에 사진을 복사한 뒤 다음 사진으로 이동합니다. 아무 앨범도 고르지 않고 **다음**을 누르면 해당 사진을 건너뜁니다.
6. 이전 사진으로 돌아가 처리 내용을 확인하거나 다른 앨범에 추가할 수 있습니다. 이미 성공한 앨범 복사는 다시 하지 않습니다. 복사 오류가 나면 현재 사진에 머물며 실패한 대상만 다시 시도할 수 있습니다.

중복 파일 이름이 있으면 `_1`, `_2`를 붙여 새 파일을 만듭니다. 여러 앨범에 한 사진을 복사해도 분류된 사진 수는 한 장으로 계산하며, **이번에 선택한 사진 목록에서 새로 복사한 파일 수**는 별도로 표시합니다. 진행 상황과 등록한 앨범은 기기에 저장됩니다.

## 삼성 갤러리에서 분류 결과 보기

삼성 갤럭시에서는 앱 홈이나 분류 완료 화면의 **삼성 갤러리 열기**를 누른 뒤, 갤러리의 **앨범** 탭에서 분류할 때 고른 앨범 이름을 여세요. 갤러리 실행 후 앨범 탭은 사용자가 직접 누릅니다. 버튼으로 갤러리가 열리지 않으면 휴대전화 앱 목록에서 **갤러리**를 직접 열 수 있습니다. 삼성 갤러리의 탭 위치나 표시 방식은 기종과 One UI 버전에 따라 다를 수 있습니다. [삼성 공식 갤러리 안내](https://www.samsung.com/us/support/answer/ANS10002535/)를 참고하세요.

분류 앱은 원본 사진을 원래 폴더에 남기고 선택한 앨범마다 실제 파일을 복사합니다. 삼성 갤러리의 **앨범** 탭에서는 폴더별로 볼 수 있지만, **사진** 탭에서는 원본과 복사본을 한곳에 모아 보여 줄 수 있습니다. 이 앱은 Google 포토를 사진 선택에 사용하지 않으며 Google 포토 화면을 바꾸지 않습니다.

## 지원 범위와 갤러리 차이

Kotlin, Jetpack Compose, MVVM, Coroutines, Preferences DataStore, MediaStore, Coil을 사용합니다. **Android 8.0(API 26) 이상**을 대상으로 하며, Android 10 이상은 MediaStore의 상대 경로와 미완료 항목 처리를 사용합니다. Android 8~9는 공유 저장소 권한과 미디어 스캔을 사용합니다.

앱의 사진 선택 및 앨범 화면은 특정 제조사의 갤러리 앱 화면이 아닙니다. 사진 선택 화면은 MediaStore에 등록된 기기 사진 폴더를 보여 주고, 사진을 넣을 대상 앨범 등록 화면은 실제 사진이 확인되는 로컬 `Pictures`/`DCIM` 앨범을 표시합니다. 삼성 갤러리에서 같은 폴더의 파일을 볼 수 있지만 화면 배치나 가상 앨범은 다를 수 있습니다. 클라우드 전용 앨범, 갤러리 내부 가상 앨범, 사진이 없는 폴더, 읽거나 저장할 수 없는 대상 위치는 그대로 선택할 수 없습니다. 이름이 같은 앨범은 내부 식별 정보로 구분합니다. Android 파일 관리자에서 폴더나 경로를 선택하게 하지 않습니다.

## 빌드 및 설치

Android Studio에서 이 폴더를 열어 Gradle 동기화 후 `app`을 실행하거나, JDK 17 이상과 Android SDK 36을 준비해 Windows 터미널에서 다음을 실행합니다.

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug assembleDebugAndroidTest
```

생성된 설치 파일은 `app/build/outputs/apk/debug/app-debug.apk`입니다. 디버그 APK이므로 개인 기기 테스트용입니다. 웹사이트에서 제공하는 APK는 별도의 릴리스 키로 서명하며, 서명 키는 이 저장소에 포함하지 않습니다. Android 휴대전화에서 설치 버튼을 누르면 APK를 내려받고 Android의 설치 확인 절차를 진행합니다. 이전에 디버그 APK를 설치했다면 서명이 달라 제거 후 릴리스 APK를 설치해야 합니다.

## 테스트 및 제한 사항

2026-10-19에 `testDebugUnitTest`, `assembleDebug`, `assembleDebugAndroidTest`, `assembleRelease`가 성공했습니다. Android 15 Pixel 6 에뮬레이터에서 기존 1.0.0 앱 위에 같은 서명 키로 1.1.0을 설치해 앨범 등록 정보가 유지되는지 확인했습니다. 두 앨범 버튼을 고를 때는 복사본이 생기지 않았고, **다음**을 누른 뒤 두 앨범에 각각 같은 사진이 복사됐습니다. 원본과 두 복사본의 SHA-256 해시가 같았으며, **이전 사진 → 다음**을 다시 눌러도 중복 복사되지 않았습니다. 아무 버튼도 고르지 않고 **다음**을 눌렀을 때는 사진을 건너뛰었습니다. 삼성 갤럭시를 포함한 **실기기 동작은 아직 검증하지 않았습니다**.

1.1.1에서 `testDebugUnitTest`, `assembleRelease`, Android 15 에뮬레이터의 계측 테스트 2개가 통과했습니다. 촬영일(EXIF)이 없는 PNG의 원본 수정 시간을 2020-01-01로 설정해 복사한 뒤, 복사본의 MediaStore `DATE_MODIFIED`와 파일 내용이 원본과 같은지 확인했습니다. 이전 릴리스와 같은 서명으로 1.1.1 APK의 업데이트 설치도 성공했습니다.

1.1.5에서는 홈과 분류 완료 화면에 **삼성 갤러리 열기** 버튼을 추가했습니다. 공개 API는 삼성 갤러리의 앨범 탭으로 직접 이동하는 기능을 제공하지 않으므로, 갤러리가 열린 뒤 사용자가 **앨범**을 누르도록 안내합니다. `testDebugUnitTest`, `assembleDebug`, `assembleRelease`, `assembleDebugAndroidTest`가 성공했고, 1.1.4와 같은 서명의 1.1.5 APK를 Android 15 에뮬레이터에 업데이트 설치했습니다. 에뮬레이터에는 삼성 갤러리가 없어 실제 삼성 갤럭시에서 버튼의 실행 화면은 확인하지 못했습니다. 원본 유지와 다중 폴더 복사 방식은 바뀌지 않았습니다.

1.2.0에서는 Android 시스템 사진 선택 화면 대신 앱 안의 휴대전화 갤러리 화면에서 로컬 앨범과 사진을 고릅니다. 기본 목록에서는 앱이 인식할 수 있는 분류 완료 사진과 앱이 만든 복사본을 숨기고, **분류한 사진 보기**로 다시 표시할 수 있습니다. 기존 Google 포토 도움말/실행 버튼은 제거했습니다. 이 목록의 표시 여부는 삼성 갤러리나 Google 포토의 화면과 파일에는 영향을 주지 않습니다. 원본 유지와 다중 앨범 복사 방식은 그대로입니다.

선택한 원본 사진의 접근 권한이 나중에 없어지거나 원본이 삭제되면 다시 선택해야 합니다. 저장소가 분리되었거나 기존 앨범 위치가 바뀐 경우에는 복사를 중단하고 오류를 표시합니다. Android 14 이상의 부분 사진 접근에서는 보이는 앨범과 수량이 전체 갤러리와 다를 수 있습니다. 앱 안의 기본 목록에서 숨기는 분류 기록과 복사본은 이 앱이 인식할 수 있는 사진에만 적용됩니다. 과거에 만든 복사본이나 외부 앱이 만든 파일은 남을 수 있습니다. 이 기능은 Google 포토 및 삼성 갤러리의 전체 사진 화면을 바꾸지 않습니다. 복사 직후 진행 기록 저장 전에 기기가 꺼지는 드문 경우에는 해당 복사를 재시도 때 구별하지 못할 수 있습니다.

사진 표시에는 기기의 이미지 디코더를 사용합니다. HEIC/HEIF는 구형 Android 8 기기에서 표시되지 않을 수 있고, AVIF도 구형 OS에서는 표시할 수 없습니다. 표시할 수 없는 사진은 분류를 진행하지 않고 다시 선택하도록 안내합니다. [Android 미디어 형식 지원표](https://developer.android.com/media/platform/supported-formats)를 참고하세요.
