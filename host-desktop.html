내 호스트 접속

호스트 접속 신청

관리자가 이 신청을 따로 승인해야 합니다. 대여 컨테이너 승인과는 별개입니다. 회원마다 별도 Kali 계정을 만들며, 서버 관리자 파일에는 접근할 수 없습니다.

접속에 사용할 PC의 .pub 공개키 한 줄을 입력하세요. 개인키는 보내지 마세요.

사이트 로그인 비밀번호와 다르게 정하고 안전하게 보관하세요. 서버에는 비밀번호 원문을 저장하지 않습니다.

접속 방법

  1. 관리자에게 Tailscale 초대를 받아 이 서버와 같은 네트워크에 PC를 연결합니다.
  2. 승인 후 표시되는 SSH 명령을 Windows PowerShell에서 실행한 채 유지합니다.
  3. Windows 원격 데스크톱 연결(mstsc)에서 127.0.0.1:13389로 접속하고 Xorg 세션을 선택합니다.

Kali 호스트의 별도 화면이 열립니다. 서버 모니터의 현재 화면을 그대로 공유하지 않습니다. 호스트 계정은 서버의 커널·자원·네트워크를 함께 사용하며 컨테이너 수준의 격리는 제공하지 않습니다. RDP는 SSH 터널로 연결하고, PC 드라이브 공유는 사용하지 않습니다.

회원 호스트 접속 승인

승인 후 회원별 Kali 계정을 준비합니다. 승인 해제 시 SSH 키와 원격 세션도 차단됩니다. 한 번에 최대 2명의 회원을 승인할 수 있습니다.
