강의가 끝나는 순간을 확인하세요.

항상 위에 뜨는 알림

강의 완료 시 Windows 경고창을 띄웁니다. 음성 안내나 강의 화면의 배너는 사용하지 않습니다.

재생률 확인

Chrome 확장 아이콘의 배지에서 재생률을 확인하고, 팝업의 알림 테스트로 연결을 점검합니다.

학교 LMS에서만

lms.cu.ac.kr의 강의 재생 상태를 읽습니다. 강의를 자동으로 넘기거나 출석 버튼을 누르지 않습니다.

설치 도우미 실행 후, Chrome에서 마무리하세요.

  1. 설치 도우미 다운로드·실행

    LectureAlarm-Setup.cmd를 더블클릭합니다. 현재 사용자 계정에 알림 프로그램을 등록하고, 확장 폴더와 Chrome 확장 관리 화면을 엽니다. 관리자 권한은 필요하지 않습니다.

  2. 개발자 모드 켜기

    Chrome 주소창의 chrome://extensions/ 화면에서 오른쪽 위 개발자 모드를 켭니다.

  3. 확장 폴더 선택

    압축해제된 확장 프로그램을 로드합니다를 누릅니다. 도우미가 보여 준 경로를 붙여 넣고 manifest.json이 들어 있는 폴더를 선택하세요. 도우미는 이 경로를 클립보드에도 복사합니다.

  4. 새로고침하고 알림 테스트

    열려 있던 LMS 강의 탭을 새로고침한 뒤 확장 아이콘의 알림 테스트를 누릅니다. 경고창이 뜨면 평소처럼 강의를 재생하세요. Chrome을 완전히 종료하면 감지도 끝납니다.

Chrome의 확인 없이 웹사이트가 확장 프로그램을 자동 등록할 수는 없습니다. 설치 도우미가 준비를 마치면 위의 개발자 모드·폴더 선택 단계를 한 번 진행하세요.

자주 묻는 내용

CMD 실행 대신 ZIP으로 설치하려면?

ZIP을 오래 보관할 폴더에 압축 해제한 뒤 설치하기.cmd를 실행하세요. 열린 Chrome에서 개발자 모드를 켜고 압축을 푼 확장 폴더를 등록합니다. 등록한 폴더는 나중에 삭제하거나 옮기지 마세요.

프로그램과 정보는 어디에 저장되나요?

설치 도우미는 확장 폴더를 %LOCALAPPDATA%\HabangTools\lecture-alarm\v2.2.0 아래에 보관합니다. Windows 알림 프로그램은 %LOCALAPPDATA%\SgangLectureAlarm에 설치되고 현재 사용자 계정의 Chrome 네이티브 메시징 호스트로 등록됩니다. 로그인 정보·강의 내용·재생 주소를 외부로 전송하지 않습니다.

경고창이 뜨지 않으면?

학교 LMS 주소와 Chrome 확장 활성화 여부를 확인하고 강의 탭을 새로고침하세요. 설치 도우미를 다시 실행해 Windows 알림 도우미를 등록한 뒤 알림 테스트를 해 보세요. 실제 재생 완료 알림을 제공하며 출석 인정 여부는 LMS에서 직접 확인해야 합니다.

업데이트하거나 제거하려면?

새 버전의 설치 파일을 받아 도우미를 실행한 다음 Chrome에서 이전 확장을 제거하고 새 폴더를 등록합니다. 제거할 때는 설치 폴더의 제거하기.cmd를 실행하고 Chrome 확장 관리 화면에서도 싸강 완료 알림을 삭제하세요.
