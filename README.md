# 사진 빠른 분류 설치 사이트

[habang222.pro](https://habang222.pro/)는 Android 사진 분류 앱의 설치 페이지입니다. 페이지의 설치 버튼은 이 저장소의 최신 GitHub Release에 첨부된 `PhotoSorter.apk`를 내려받습니다.

처음 설치하는 사용자를 위한 실제 화면 설명서는 [guide.html](guide.html)에 있습니다. Android 15 Pixel 6 에뮬레이터에서 캡처한 앱 화면으로 설치, 사진 권한, 앨범 등록, 여러 앨범 버튼 선택과 **다음**을 누른 뒤 복사하는 방법을 안내합니다. 삼성 갤럭시 설정은 삼성 공식 화면 안내로 연결합니다.

Android 앱 소스와 빌드 안내는 [android/README.md](android/README.md)에 있습니다. APK는 Android 8.0 이상에서 설치할 수 있으며, 휴대전화의 설치 확인과 최초 사진 접근 권한 선택은 사용자가 직접 합니다.

새 버전을 배포할 때는 기존 릴리스 서명 키로 APK를 빌드하고, 새 GitHub Release에 파일 이름 `PhotoSorter.apk`로 첨부하세요. 설치 페이지는 최신 릴리스를 가리키므로 같은 파일 이름을 유지하면 링크를 바꿀 필요가 없습니다. 서명 키와 비밀번호는 저장소에 올리지 마세요.
