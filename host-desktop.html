Kali 원격 데스크톱

회원마다 분리된 Linux 계정과 화면으로 서버 컴퓨터에 접속합니다.

계정 상태를 확인하고 있습니다.

회원 인증이 필요합니다

이메일 인증과 회원가입을 마친 뒤 접속을 신청할 수 있습니다.

내 호스트 접속

호스트 접속 신청

관리자가 이 신청을 따로 승인해야 합니다. 대여 컨테이너 승인과는 별개입니다. 회원마다 별도 Kali 계정을 만들며, 서버 관리자 파일에는 접근할 수 없습니다.

고급 설정: SSH 공개키 (선택)

웹 원격 접속에는 필요하지 않습니다. 별도 SSH 터널을 사용할 때만 공개키를 입력하세요. 개인키는 보내지 마세요.

영문·숫자·기호 12~72자로, 사이트 로그인 비밀번호와 다르게 정하세요. 서버에는 비밀번호 원문을 저장하지 않습니다.

내 Kali 작업 화면

원격 비밀번호를 입력하면 이 페이지에서 바로 연결됩니다.

다른 Wi-Fi나 외부 네트워크에서도 사용할 수 있습니다. 화면을 클릭하면 키보드·마우스를 사용할 수 있으며, 전체 화면에서는 Esc로 돌아옵니다. 한 계정에서 원격 창은 하나만 열 수 있습니다. 30분 동안 조작하지 않거나 2시간이 지나면 연결을 종료합니다.

웹 원격 이용 안내

  1. 이메일 인증과 회원가입을 마친 뒤 Kali 호스트 접속을 신청합니다.
  2. 관리자 승인 후 이 페이지에서 전용 원격 비밀번호를 입력합니다.
  3. 브라우저 안의 Kali 화면에서 작업합니다. 외부 프로그램이나 Tailscale 연결은 필요하지 않습니다.

회원마다 별도 Kali 계정과 작업 화면을 사용합니다. 서버 모니터의 관리자 화면을 공유하지 않습니다. 호스트 계정은 서버의 커널·자원·네트워크를 함께 사용하며 컨테이너 수준의 격리는 제공하지 않습니다. 화면 중계에 사용한 Apache Guacamole 라이선스를 확인할 수 있습니다. 연결 종료는 로그아웃이 아니므로 작업을 마칠 때 Kali 메뉴에서 로그아웃해 주세요.

회원 호스트 접속 승인

승인 후 회원별 Kali 계정을 준비합니다. 승인 해제 시 SSH 키와 원격 세션도 차단됩니다. 한 번에 최대 2명의 회원을 승인할 수 있습니다.
