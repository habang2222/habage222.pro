RANDOM PASSWORD BACKSPACE

백스페이스 한 번,
삭제는 무작위로.

비밀번호 입력창에서 Backspace를 누르면 바로 앞의 1~3글자를 무작위로 지웁니다. 입력창 옆에 실제 삭제 수를 표시하고, 일반 검색창이나 텍스트 입력창은 평소대로 사용할 수 있습니다.

Google Chrome비밀번호 입력창 전용실험용 도구
Windows 설치 도우미 받기 ↓ZIP 직접 받기 · 모든 OS

Windows 도우미가 파일 다운로드·압축 해제와 설치 화면 열기를 처리합니다. Chrome 확장 등록은 직접 확인해야 합니다. macOS·Linux에서는 ZIP을 사용하세요.

비밀번호를 입력할 때만 동작합니다.

1~3글자 무작위 삭제

커서 앞의 글자를 지우고 실제 삭제 수를 알려줍니다. 남은 글자가 적으면 남은 만큼만 삭제합니다.

필요할 때 켜고 끄기

확장 아이콘에서 기능과 알림을 각각 켜고 끕니다. 알림 표시 시간은 300~5000ms로 조절합니다.

기기 안에서 처리

비밀번호나 키 입력 이력을 저장·전송하지 않습니다. 저장되는 것은 기능과 알림 설정뿐입니다.

키 소리·진동으로 입력을 추정하는 관찰자에게 삭제 수의 불확실성을 더하려는 실험입니다. 실제 방어 효과는 검증되지 않았으며, 무작위 삭제로 입력이 불편해질 수 있습니다.

도우미로 준비하고, Chrome에서 등록하세요.

  1. 설치 도우미 다운로드·실행

    Windows에서 RandomBackspace-Setup.cmd를 더블클릭합니다. 확장 파일을 고정 폴더에 풀고, 해당 폴더와 Chrome 확장 관리 화면을 엽니다. 관리자 권한은 필요하지 않습니다.

  2. 개발자 모드 켜기

    chrome://extensions/에서 오른쪽 위 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 누릅니다.

  3. 확장 폴더 선택

    도우미가 보여 준 경로를 붙여 넣고 manifest.json이 들어 있는 폴더를 선택하세요. 도우미는 경로를 클립보드에도 복사합니다. 직접 받은 ZIP은 압축을 푼 폴더를 선택합니다.

  4. 웹페이지 새로고침

    열려 있던 페이지를 새로고침하세요. 비밀번호 입력창에 시험용 문자열을 입력하고 Backspace를 누르면 삭제 개수 알림이 나타납니다. 실제 비밀번호를 제출하기 전에는 입력 내용을 다시 확인하세요.

배포 기준: f64bdb1. 설치 도우미의 보관 위치는 %LOCALAPPDATA%\HabangTools\random-backspace\f64bdb1입니다. 등록한 폴더는 삭제하거나 이동하지 마세요.

사용·권한·설정

Chrome에서 어떤 권한을 요청하나요?

설정을 보관하는 storage 권한과 일반 HTTP·HTTPS 사이트의 비밀번호 필드에 적용할 접근 범위를 사용합니다. Chrome 확장 설정의 사이트 접근에서 사용 범위를 줄일 수 있습니다. 비밀번호, 키 입력·삭제 이력은 저장하거나 서버로 전송하지 않습니다.

어떤 입력은 원래대로 동작하나요?

일반 텍스트·이메일·검색 입력창, 선택 영역 삭제, Ctrl·Alt·Meta·Shift 조합키, IME 조합 중인 입력은 기존 동작을 유지합니다. 브라우저 내부 페이지나 닫힌 Shadow DOM 같은 제한된 입력창에서는 적용되지 않을 수 있습니다.

모든 로그인 화면에서 사용할 수 있나요?

일부 사이트가 자체 입력 처리나 합성 이벤트 제한을 사용하면 호환되지 않을 수 있습니다. 입력이 맞지 않으면 확장 아이콘에서 기능을 끄고 다시 입력하세요. 화면을 보는 사람이나 화면 녹화·악성 프로그램으로부터 비밀번호를 보호하는 기능은 아닙니다.

macOS·Linux 설치 또는 제거는 어떻게 하나요?

ZIP을 고정 폴더에 압축 해제하고 Chrome의 개발자 모드에서 해당 폴더를 로드하면 됩니다. 제거는 chrome://extensions/에서 랜덤 백스페이스의 삭제 버튼을 사용하세요. 이후 보관 폴더를 지울 수 있습니다.
