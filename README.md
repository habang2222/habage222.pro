# habang222 블로그와 사진 빠른 분류 앱

[habang222.pro](https://habang222.pro/)는 프로젝트를 검색하고 태그로 찾아볼 수 있는 메인 페이지입니다. **사진 빠른 분류** 버튼을 누르면 [앱 소개·설치 페이지](photo-sorter.html)로 이동합니다. 앱 페이지의 설치 버튼은 이 저장소의 최신 GitHub Release에 첨부된 `PhotoSorter.apk`를 내려받습니다.

메인에 링크를 추가하거나 바꾸려면 저장소의 [links.js](links.js) 목록을 수정하고 `main` 브랜치에 반영합니다. 각 항목에 `title`, `description`, `url`, `category`, `tags`를 적으면 검색과 태그 필터에 자동으로 포함됩니다. `url`은 `https://...` 또는 같은 사이트의 `photo-sorter.html` 같은 경로를 사용할 수 있습니다. 사이트 방문자용 링크 입력 기능은 없습니다. 버튼 그림은 [images/home](images/home) 안의 투명 배경 이미지 네 장을 페이지를 열 때마다 무작위로 배정합니다. 첫 번째 제공 사진은 메인 상단 배경으로 사용합니다.

처음 설치하는 사용자를 위한 실제 화면 설명서는 [guide.html](guide.html)에 있습니다. Android 15 Pixel 6 에뮬레이터에서 캡처한 앱 화면으로 설치, 사진 권한, 앨범 등록, 앱 안의 휴대전화 갤러리에서 사진 고르기, 여러 앨범 버튼 선택과 **다음**을 누른 뒤 복사하는 방법을 안내합니다. 사진을 고르는 화면은 기기에 저장된 사진과 앨범을 보여 주는 이 앱의 화면이며, 삼성 갤러리 앱 자체를 앱 안에 넣은 것은 아닙니다. 분류 후에는 앱의 **삼성 갤러리 열기**를 누르고 갤러리의 **앨범** 탭에서 폴더별 결과를 볼 수 있습니다. 삼성 갤럭시 화면은 직접 캡처한 것으로 표시하지 않으며, 삼성 공식 화면 안내로 연결합니다.

분류 앱은 원본을 남기고 선택한 폴더마다 실제 복사본을 만듭니다. 앱의 사진 선택 화면은 분류 기록과 앱이 만든 복사본을 인식하는 경우 기본 목록에서 숨기고, **분류한 사진 보기**로 다시 볼 수 있습니다. 이 표시는 이 앱 안의 목록에만 적용됩니다. 삼성 갤러리의 **사진** 탭과 Google 포토의 **사진** 화면에는 원본과 복사본이 함께 보일 수 있습니다. 삼성 갤러리로 사진을 보는 것만으로 Google 포토 화면이 정리되지는 않습니다.

Android 앱 소스와 빌드 안내는 [android/README.md](android/README.md)에 있습니다. APK는 Android 8.0 이상에서 설치할 수 있으며, 휴대전화의 설치 확인과 최초 사진 접근 권한 선택은 사용자가 직접 합니다.

새 버전을 배포할 때는 기존 릴리스 서명 키로 APK를 빌드하고, 새 GitHub Release에 파일 이름 `PhotoSorter.apk`로 첨부하세요. [앱 설치 페이지](photo-sorter.html)는 최신 릴리스를 가리키므로 같은 파일 이름을 유지하면 링크를 바꿀 필요가 없습니다. 서명 키와 비밀번호는 저장소에 올리지 마세요.
